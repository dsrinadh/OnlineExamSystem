# 🖥️ Online Exam System

## 📌 Project Title
Online Exam System using Java (Swing + JDBC)

---

## 📖 Project Description
The Online Exam System is a desktop-based application developed in Java.  
It allows students to log in, attend multiple-choice exams, and automatically calculates scores.  
The system uses JDBC for database connectivity and Swing for the graphical user interface.

This project is designed to simulate a real-time online examination environment with secure login, timer-based tests, and instant result generation.

---

## ✨ Features
- 🔐 User Login System
- 📝 Multiple Choice Questions (MCQ) Exam Interface
- ⏱️ Timer-based Exam System
- 📊 Automatic Score Calculation
- 🧾 Result Display Page
- 🗄️ Database Connectivity using JDBC (MySQL)
- 💻 Simple and User-Friendly GUI (Java Swing)

---

## ⚙️ Software Requirements
- Java JDK 8 or above
- NetBeans / Eclipse / IntelliJ IDEA
- MySQL Database
- MySQL Connector JAR
- Windows / Linux / Mac OS

---

## 🚀 Steps to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/OnlineExamSystem.git

2.Open the project in any Java IDE (NetBeans/Eclipse/IntelliJ).
3.Import the MySQL connector JAR file (if not already included).
4.Configure the database:
  Create a MySQL database
  Import required tables (if provided)
5.Update database credentials in DBConnection.java.
6.Compile and run the project:
  Run Login.java or Main.java
  Compile-javac -cp ".;lib/mysql-connector-j-9.7.0.jar" src/*.java
  run-java -cp ".;src;lib/mysql-connector-j-9.7.0.jar" Main
